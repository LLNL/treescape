Changelog
=========

All notable changes to TreeScape will be documented in this file.

Version 1.0 (2025-01-XX)
------------------------

Initial release of TreeScape documentation.

**Features:**

* CaliReader with parallel file loading
* ThicketReader for Thicket integration
* TreeScapeModel for managing performance runs
* StackedLine interactive visualizations
* MultiLine matplotlib plotting
* SVG export capabilities
* Comprehensive API documentation
* Example notebooks and scripts

**Known Issues:**

* None at this time
